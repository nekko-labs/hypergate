# Logins outside Hypergate, one list

- The Ambient logins panel in Credentials now lists only what is outside Hypergate right now. Each login either offers **Move into Hypergate** or says **Not supported** when Hypergate can't import that kind of login yet (Azure, AWS, Google Cloud, Docker, netrc). **Details** still explains how to handle those by hand.
- The "Recently noticed" history is gone from the panel. Desktop and team alerts for new logins and CLIs work as before.
