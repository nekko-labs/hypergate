# Updates repair what moved

Hypergate now fixes what a moved folder, a rename or an old test left behind, every time it starts.

### Bug fixes

- **Hypergate starts at login again.** A test in Hypergate's own suite wrote the real "start at login" entry and put its own test runner there, so on a developer machine Hypergate stopped starting once that checkout was removed. On start, Hypergate now checks its login item: if what it launches is gone (a moved or uninstalled copy, a deleted checkout, a node upgrade) or is a test runner, it is pointed back at this install. A login item you never turned on stays off.
- **Nekko Agent finds its own agent after its rename.** An agent saved as Kotrain, Agent Nekko, Nekkos or Open Paw is now called Nekko Agent, with the same token, permissions and history, so the app reconnects to it instead of creating a second one.
- The Nekko Agent snippet names `~/.nekko-agent/settings.json`, where the app keeps its data now.
- Hypergate's tests no longer touch the login item or the data folder of whoever runs them.
