# Install, repair, and remove CLIs from the app

The Command-line tools section stops at nothing: every tool it can find, it can now install for you, with the log on screen. Agents get the same power with a human in the loop.

### Features

- **Install from the row.** Every install route Hypergate can run itself carries an Install button beside the command and Copy. Output streams into the row as a live log with a Stop button, and the row flips to installed when it lands. Script and download routes stay copy-only on purpose.
- **Your package manager, not just npm.** An npm-distributed tool now also offers pnpm, yarn, and bun routes, curated tools keep their vendor's winget, Homebrew, and Scoop routes per OS, and Hypergate checks which managers your machine actually has so a button is never a dead end.
- **Installed tools can be managed.** A search result you already have offers Repair and a two-step Uninstall per route; a curated tool's Manage panel adds its vendor's sign-in command (run in-app when it works without a terminal, honestly explained when it doesn't) and picks the route matching where the tool actually lives, so a Homebrew gh gets `brew reinstall gh`, not an npm guess.
- **Agents ask, you approve, everyone sees the log.** Agents connected to the gateway can list this machine's CLIs, search the catalog, and file an install request with a reason. A badge appears on CLI tools; Install & approve runs it in the manager with the log visible, Deny runs nothing. Agents never install directly.
- **The gateway says so.** Its instructions now tell every connecting agent that CLIs, MCP servers, and credentials are managed through Hypergate, so agents stop improvising installs or asking you to run them by hand.
