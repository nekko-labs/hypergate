# Building a release tells you when it cannot

### Bug fixes

- **Building the installers locally failed with an unreadable error.** On a machine whose Node came from Homebrew, `npm run build:installers` died with a bare stack trace and no message. The underlying reason is that Homebrew builds Node against shared libraries, which makes it unable to produce a single-file executable and, more importantly, unable to produce one that would run on anyone else's machine.

  The build now checks for both problems before it starts, uses an official Node automatically if one is installed (fnm, nvm, volta, asdf, or `/usr/local/bin`), and otherwise stops with an explanation and the fix. It also says outright that the Node *version* is not the problem, because "update Node" is the natural conclusion and the wrong one.

Published releases were never affected: CI has always built them with official Node.
