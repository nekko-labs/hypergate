# Release highlights and the people behind them

### Features

- **Find major features and who shipped them.** Hypergate's release notes now lead with a timeline of published highlights, each with contributor and pull request links, followed by the recent release archive and installers.
- **Manage instructions inside each connected agent’s row.** Expand an agent to add, update, or remove its Hypergate instructions.
- **See which detected agents aren’t connected.** The Agents page now lists them separately, with a Connect button for each.
- **Find team access under People.** People has its own sidebar page, where you can invite teammates and manage their access.
