# Remove means removed, and the app is a window

One Remove that really removes, a tools list that stops crying wolf, and an app that finally behaves like a window. Includes everything from v0.16.0.

### Features

- **Remove now means removed.** Removing a server stops it, signs it out completely, deletes its settings, and takes it out of every agent's allow-list. Before this, Remove left the sign-in behind in your keychain, so re-adding the same server came back already signed in as whoever set it up last. Disconnect and Remove were one decision wearing two buttons, so there is a single control now, and it asks twice ("Remove & sign out") because the cost of a misclick is signing in again.
- **Tools you have not installed are an offer, not a fault report.** The CLI section used to list all 22 tools it knows about and pin a "missing" label on the ones you do not have, which reads as though something is broken when all it means is that you have not installed it. It now lists what you actually have, and the rest sit behind "Install a tool", each with the control its install really needs: a command to copy, a link to open, or a plain note that it ships with something else.
- **The app is a window now, not a web page in an app frame.** The top bar and footer stay put and every list scrolls on its own, so resizing changes how much of each list you see instead of pushing the footer off the bottom of the screen. Panels share the height available in proportion to how much each has to show, and a panel you open on purpose scrolls itself into view instead of opening below the fold.
- **Analytics fits on screen.** Usage by server and Who's calling sit side by side while the window is wide enough and stack when it is not. On a short window the explanatory text steps aside so the numbers get the room.
- **The mark in the top bar is the gate again.** It was the favicon on a gradient tile, two backgrounds arguing with each other. It is now the ring from the site's hero rebuilt for a 28px space: violet through cyan to ice, turning once every seven seconds around a centre that breathes. The favicon is the same mark held still. Both animations stop if your system asks for reduced motion.

### Bug fixes

- **Links out of the desktop app went nowhere.** "Sign in" on a remote server did nothing at all, and neither did any docs link, the release notes link, or the GitHub mark in the footer. They all worked in a browser tab, which is why it went unnoticed. They now open in your real browser, which is where you are already signed in, and a much better place to type a GitHub password than a window with no address bar. Only web links get passed along.
- **The window opens at a size that fits your screen.** It now opens at 1360x900 and shrinks to fit a smaller monitor, instead of opening partly below the bottom edge of a laptop screen.
- A sign-in saved by an older version could white-screen the whole page. At worst it now shows one incomplete account chip.
