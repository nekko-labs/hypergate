# Remove means removed, and the app is a window

One Remove that really removes, a tools list that stops crying wolf, and an app that finally behaves like a window. Includes everything from v0.16.0.

### Features

- **Remove now means removed.** Removing a server stops it, signs it out, deletes its settings, and removes it from agent allow-lists.
- **Missing tools are offers, not errors.** The CLI section lists installed tools and puts installation options for the rest behind one control.
- **The app behaves like a window.** Fixed navigation and independently scrolling panels make resizing and long lists predictable.
- **Analytics fits on screen.** Its main views sit side by side when possible and stack cleanly in smaller windows.
- **The top-bar mark is the gate again.** The app and favicon share a hollow, reduced-motion-aware gate mark.

### Bug fixes

- **Links out of the desktop app went nowhere.** Web links now open in the system browser.
- **The window opens at a size that fits your screen.** Its default dimensions shrink to fit smaller monitors.
- **Older sign-ins could white-screen the page.** They now show an incomplete account chip instead.
