# One title bar instead of two

The desktop window loses its system frame, so the app's own top bar becomes the window's title bar.

### Features

- **The Hypergate mark now sits in the window's top-left corner.** The name used to appear twice — once in the system title bar, once in the app below it. The system bar is gone and the app's is the real one.
- **The version pill, theme control and health chip moved to the top right.** They sit on the same line as the minimise, maximise and close buttons, which are drawn in the app's own background instead of in a strip of system chrome above it.
- **Dragging the top bar moves the window, double-clicking it maximises.** Snapping and dragging to an edge keep the maximise button in step.
- **macOS keeps its traffic lights.** They float over a transparent title bar, lined up with the wordmark, so the window still behaves like a Mac window.
- **The footer stretches across the window.** "Local-first · MIT" sits at the left edge and the GitHub mark at the right, mirroring the bar at the top.
- **Nothing changes in a browser tab.** The same page served at the daemon's address keeps the tab's own chrome and draws no window buttons.
