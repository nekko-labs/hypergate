# Midnight

Hypergate's dark theme is now Midnight, a deep blue-black that matches hypergate.app.

### Changes

- **Midnight dark theme.** The manager's default dark theme moves from mid-slate to Midnight (`#0a0c16`) with lifted blue cards. The theme-switch sweep and the startup window use the same surfaces, so nothing flashes slate on the way in. Light is unchanged.
- **hypergate.app: connect everything once, for all.** The site now leads with what one gate does for everyone: connect every MCP server, connector, agent, and skill to Hypergate once, and everyone who connects gets it. A new Connect once section covers one-click setup, permissions per human or per agent, and visibility into what your agents use. The site background is Midnight too.
