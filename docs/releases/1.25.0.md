# Homebrew installs finish in the app

### Bug fixes

- **Homebrew installs no longer stop after fetching dependencies.** Homebrew 6 uses ask mode by default for `install` and `reinstall`, while Hypergate closes stdin for lifecycle jobs so an interactive process cannot hang. That combination could print the install plan, update dependencies, stop before pouring the requested formula, and still return exit code 0, so Hypergate reported success even though no CLI appeared.

  Hypergate now sets Homebrew's documented `HOMEBREW_NO_ASK=1` only for daemon-spawned `brew` jobs. Install and Repair therefore complete without a terminal. The command shown in the app stays the same, other package managers are untouched, and `hypergate cli install` remains interactive when run in a terminal.
