# The Mac app looks and starts like an app

A follow-up to 1.0.0 fixing what the first macOS installs ran into, plus a faster landing page.

### Bug fixes

- **The Mac app has its own icon.** Installing the 1.0.0 `.pkg` left a blank generic icon in Launchpad and the Dock; the app now carries the Hypergate mark at every size, including retina.
- **The first launch no longer opens a dead page.** The window used to appear after a fixed wait and show an error page if the background service was not ready yet, with no way back except quitting. It now opens on a "Starting Hypergate…" screen, moves to the app as soon as the service answers, and offers Retry and a browser link if it never does.
- **The app is usable while servers are still starting.** The dashboard, the health check and the management API used to wait for every enabled MCP server to boot, so one slow server made the whole app look down.
- **The Intel Mac installer no longer refuses to install.** The x64 `.pkg` claimed to be an Apple Silicon package, so macOS rejected it on Intel Macs.
- **Startup problems leave a trace.** Launched from Finder the app had nowhere to print diagnostics, so a failed start was silent; it now writes `~/.hypergate/hypergate.log` (size-capped, with credential-shaped values redacted).

### Performance improvements

- **The hypergate.app hero arrives in about half the time.** The entrance animation settles in ~0.77s instead of ~1.74s and no longer animates blur, so the text is readable sooner and scrolling stays smooth while it plays.
