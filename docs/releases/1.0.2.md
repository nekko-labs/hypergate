# A safer install, and a CLI agents can run

Hypergate 1.0.2 closes local browser attack paths, makes updates verifiable, and lets an agent manage the whole install without opening the manager.

### Features

- **An agent-ready CLI.** `doctor`, global `--json`, scoped credentials with in-place token rotation, harness connection, CLI catalog lookup, safe curated installation, and usage history cover the management work an agent previously needed the UI to do.
- **Safer local management.** A web page cannot make the local management API mutate anything on the user's behalf, and DNS rebinding cannot disguise an attacker host as Hypergate.
- **Verified release updates.** GitHub release tarballs now use SHA-256 checksums just like npm updates, before anything is staged or installed.
- **Cleaner native installs.** Windows upgrades stop only Hypergate processes belonging to that installation and preserve expandable PATH entries; Linux refreshes desktop and icon caches immediately; macOS includes an uninstaller.

### Bug fixes

- **Redaction stays valid UTF-8.** Secret-shaped text is searched without splitting a multibyte character.
- **macOS launchers no longer collide by case.** Installer and launcher paths remain safe on case-insensitive filesystems.
