# Hypergate shows its icon

### Features

- **Hypergate has a name and icon in your MCP clients.** When an agent connects, Hypergate now introduces itself as "Hypergate" with the app icon, so apps that list their MCP connections can show it instead of a blank tile. The icon travels inside the connection itself, so it works even when the app can't reach your machine's address.

### Bug fixes

- `/favicon.ico` returns the app icon. It used to return the manager's page.
