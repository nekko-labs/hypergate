# Midnight Gate

The manager now looks like it comes from the same place as hypergate.app.

### Changes

- **A design system shared with the site.** The midnight canvas now carries the gate's light (violet at the top, cyan at the bottom) and a faint field of stars, running up under the title bar. Cards are midnight blue with blue hairlines, and the row you have open is the one that glows.
- **New buttons.** Buttons are capsules, as on the site. The main action on a screen is the violet-to-cyan gradient and lifts into a cyan glow on hover; add and connect actions are a cyan outline; everything else is a quiet outline that warms to violet.
- **The site's type.** Page titles, metrics and dialog titles use Space Grotesk, section headings are the site's cyan mono kickers, and values you copy (the gateway URL, tokens, paths) are set in JetBrains Mono, with the URL in ice. The fonts ship inside the app, so it looks the same offline and on machines without them installed.
- **Light theme** follows the same rules on a pale canvas.

### Bug fixes

- The restart and remove icons on server and agent rows were squeezed to a few pixels; they are full size again.
- The 24-hour calls chart drew every quiet hour as a tall empty box and pushed the current hour off the end. Quiet hours are a thin baseline again, and the current hour shows.
