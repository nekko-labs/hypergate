# The Mac build ships the new mark

v1.6.0 could not finish building for macOS, so this is the same release with the Mac icon fixed.

### Bug fixes

- **The macOS app icon follows the softened gate.** The packaging-only copy of the mark that macOS installers are built from still drew the old hard-edged ring with its pale top arc, and its drift guard stopped the Mac build outright. It now renders the same feathered ring, blooming crests and outer halo as the app itself, verified pixel-for-pixel against the shipped renderer.
