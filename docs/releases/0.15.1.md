# Updates that finish, and Intel Mac builds again

Both fixes are about a release reaching you: one in the update itself, one in the build that produces it.

### Bug fixes

- **After a one-click update, the app could sit on the old version indefinitely.** It decided the install was over by watching for its background service to stop answering, but the service that comes back answers perfectly well, and reported a job it knew nothing about. Both paths now watch for the version that is serving to change, which is the question that was being asked all along.
- **Intel Mac builds are built again.** That job asked for a build machine Apple has retired, so it did not run slowly, it did not run at all: one build sat in the queue for 24 hours before it was cancelled, and v0.15.0 was heading the same way. Intel builds are now cross-compiled on the Apple silicon machine.
