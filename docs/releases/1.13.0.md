# About stops crashing, and one Install button

A crash fix and two pieces of polish on the day-old CLI section.

### Bug fixes

- **About Hypergate no longer crashes the Mac app.** The About panel read menu data whose memory had already been freed, so clicking it crashed whenever the allocator had reused that memory. The menu now lives as long as the app does.
- **Install buttons are never silently dead.** A single failed lookup of your package managers used to disable every Install button for good, with only a tooltip saying why. The lookup now refreshes with the list, an unknown answer leaves the button live (the daemon gives a real error if it must), and a genuinely missing manager says so in text under the command.

### Features

- **One Install button, one choice.** Each tool's install routes are now a horizontal npm / pnpm / yarn / Homebrew toggle with a single action button that runs whatever is selected, instead of a button per route. Vendor script routes say plainly that they are copy-only.
- **The Updates section names your version.** "You're on the latest version" now reads "You're on the latest version, v1.13.0".
