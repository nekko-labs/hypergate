# The Mac app can update itself

After one final manual install, future Hypergate updates can happen entirely inside the Mac app.

### Features

- **Download and install replaces How to update on macOS.** Hypergate now downloads the signed release, verifies it, replaces the app safely, and restarts on its own while keeping every server and setting.

### Bug fixes

- **The updater now matches how the Mac app is installed.** It replaces the complete notarized app instead of trying to write package files into an Apple-sealed bundle.

### Before updating

- **Version 1.7.2 needs one final manual update.** Install 1.8.0 from its disk image once; updates from 1.8.0 onward can use the in-app button.
