# Agents can ask for a key, and you can see one again

The credential vault from v1.7.0, from the other side of the gateway: an agent that needs a key now knows the vault exists, can ask you for access, and gets a link that takes you straight to the decision.

### Features

- **An agent that needs a key asks for it instead of asking you to paste one.** The gateway tells every connecting agent that this machine's keys live in Hypergate, and a new request tool files an access request with a short reason. You get a badge on Credentials, the agent gets a link to hand you, and approving it grants exactly that one key to exactly that one agent.
- **A refusal is no longer a dead end.** An agent denied a credential files the request automatically, so the error it reports already tells you where to go.
- **54 providers, searchable.** The add flow grew from 8 guided services to 54 across eight categories, searchable by product, CLI name, or environment variable: `fly`, `flyctl`, and `FLY_API_TOKEN` all find the same row. Every link goes to the provider's own token page.
- **Add your own credential is its own thing.** It used to sit at the bottom of the provider list looking like another provider. It is now a separate block, because it answers a different question.
- **You can see a stored value again, with permission.** Reveal asks the OS to confirm it is you (Touch ID on macOS, Windows Hello on Windows, polkit on Linux), shows the value once, and hides it again after 30 seconds. Every reveal is recorded in Analytics. Where a machine has no way to ask, the button says so rather than falling back to something weaker.

### Bug fixes

- **Cmd+V works in the Mac app.** Pasting into the credential fields did nothing while right-click Paste worked, because the app had no menu bar and macOS delivers the standard editing shortcuts through one. The app now has a proper Edit menu, which fixes Cut, Copy, Paste, Select All, Undo and Redo everywhere in the window.

### Notes

- Agents can see the *names* of keys they have not been granted, so they can ask for them. They never see a value or even the masked hint. If you would rather they saw nothing at all, turn off **Agents can see credential names** in Settings.
- Reveal needs the `hypergate` command-line binary to be v1.9.0 or newer. If the app and the CLI are installed separately and the CLI is older, Reveal explains that instead of failing silently.
