# The Mac download says Apple silicon

Hypergate on macOS is now an Apple silicon app, and the download says so in words rather than in a chip name.

### Features

- **The Mac download is called Apple silicon.** The disk image is published as `hypergate-macos-apple-silicon.dmg`, and the site's button reads **Download for Mac (Apple silicon)**. The old `hypergate-macos-arm64.dmg` link still works, and in-app updates are unaffected.
- **An Intel Mac is told it cannot run Hypergate.** Instead of being handed a disk image that will not open, an Intel visitor sees **Needs an Apple silicon Mac**, and an Intel install that checks for updates is offered none.

### Bug fixes

- **The releases that failed all failed on the Intel build.** Intel macOS builds have had to be cross-compiled since GitHub retired its last Intel runner, so nothing in CI could launch, notarize a run of, or smoke-test what they produced. Dropping them removes the step whose disk image build failed v1.7.1's release while the Apple silicon one succeeded.

### Before updating

- **Intel Macs stay on 1.8.0.** There is no 1.9.0 build for them, and they will not be offered one.
