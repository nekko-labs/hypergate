# Agent-first navigation, and rows that open

Servers and agents are now rows you can open, and a quiet left rail keeps you oriented as the lists grow.

### Features

- **Open a server row to see its details.** Expanded rows show tools, allowed agents, and live logs in one place.
- **Collapsed rows show useful server status.** Each row includes its latest log line and a compact tools-and-agents summary.
- **Agent rows open the same way.** Opening one reveals its token, allowed servers, and connection instructions.
- **Controls are quieter.** Start, restart, and remove actions stay together and secondary actions appear on hover.
- **A left rail separates manager sections.** Servers, agents, and CLI tools each get their own navigable space.
- **The site leads with a download.** Hypergate now offers a platform-specific installer, release notes, and a matching launch command.

### Bug fixes

- **The animated gate had faint rectangular seams.** They are gone from hypergate.app.
- **The site's connect snippet was hard to adapt.** It now shows a tested command for the current platform.

### Performance improvements

- **Server status uses existing polling.** Latest-log lines add no requests regardless of server count.
- **Expanded panels stay bounded.** Tool lists and log panes scroll internally instead of growing the window.
- **Open logs follow selectively.** They refresh every three seconds and follow new lines only when already at the bottom.
