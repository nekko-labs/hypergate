# Agent-first navigation, and rows that open

Servers and agents are now rows you can open, and a quiet left rail keeps you oriented as the lists grow.

### Features

- **Open a row to see everything about one server.** Click any server row and it expands in place, onto its tools, the agents allowed to reach it, and its live logs. The three buttons that used to sit on every row all answered the same question, so now they are one click.
- **A collapsed row tells you how the server is actually doing.** Each row shows the last line the server wrote, dimmed, so a server that is quietly ready no longer looks identical to one that is complaining every second. The summary reads like `3 tools · 1/2 agents`, and turns amber when no agent is allowed to reach that server at all.
- **Agent rows open the same way**, onto the agent's token, the servers it may use, and how to connect it. The separate Connect button is gone, because opening the row already does that.
- **Quieter controls.** On/off, restart and remove now sit together at the right edge of a row. Restart and remove stay faint until you point at the row, so no red trash can is shouting in every row you scan. Remove still asks a second time before it does anything.
- **A left rail for getting around.** Servers, agents and CLI tools each get room to breathe instead of competing for one cramped scrollbar, and the rail follows whichever section you have scrolled to. On a narrow window it collapses to a compact strip.
- **The site leads with a download.** hypergate.app now hands you the installer for your own platform, has a release notes page, and shows an install-and-launch command written for the machine you are reading it on.

### Bug fixes

- The faint rectangular seams around the animated gate on hypergate.app are gone.
- The site's connect snippet was a command you had to adapt by hand. It is now a real, tested command for your platform.

### Performance improvements

- The last-log line on each row rides the status the app already polls, so it costs no extra requests no matter how many servers you run.
- An open row's tool list and log pane each stop growing and scroll on their own, so a server with 60 tools cannot push the window out of shape.
- An open row tails its log every three seconds, and only follows new lines while you are already at the bottom of it.
