# Release notes you can actually read

### Features

- **Every release says what changed, not just how to install it.** Notes are grouped into Features, Bug fixes and Performance improvements, in plain words, with the install instructions moved to the bottom where they belong. The four earlier releases were rewritten the same way, so the whole history reads as something written for the person deciding whether to update.
- **A release is named by what it did.** Every entry on [the release notes page](https://hypergate.app/release-notes.html) leads with a headline instead of printing the version number twice.
