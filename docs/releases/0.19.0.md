# Connect once and stay connected, plus a plugin and a bundle

Everything since v0.17.0, including the v0.18.0 changes that were never released on their own.

### Features

- **Connecting a client no longer hands it a token that goes stale.** A client used to get a copy of a gateway token in its config, where it sat until the token rotated or the agent was re-created, and then the client was simply broken while Hypergate still showed the agent as connected. Clients that can run a command at connect time now fetch the credential when they connect, and again if it is refused, so a rotated token or a re-created agent costs a reconnect instead of a mystery. Every other client keeps the plain token, which is what it can actually read.
- **Hypergate installs into Claude Code as a plugin.** `/plugin marketplace add nekko-labs/hypergate`, then `/plugin install hypergate@nekko-labs`, and the gateway is there in every project with no token, no port and no JSON to paste.
- **Every agent in "+ Add agent" carries its own company's mark** instead of a letterform, each kept in the proportions its brand drew it in rather than squashed into a square. **Warp and Antigravity** join the list too, each with the config file and snippet shape it actually reads.
- **One sun and moon button for the theme**, switching with a circular reveal instead of a menu.
- **Dialogs, toasts and focus behave for a keyboard and a screen reader**, from a UI and accessibility audit pass over the manager.
- **Release notes you can read.** Every release now says what changed, grouped into Features, Bug fixes and Performance improvements, with the install instructions at the bottom where they belong. The four earlier releases were rewritten the same way, and each entry on [the release notes page](https://hypergate.app/release-notes.html) leads with a headline instead of printing the version number twice.
- **The site leads with what you are weighing.** "One gate." became "One secure gate.", and the subhead is now about connecting Claude Code, Codex, Kotrain, Cursor or Devin to GitHub, Vercel, Slack or Google Drive without putting your keys and permissions in an agent's hands.
- **Kotrain is Kotrain again.** The sibling product was renamed to Nekkos and renamed back within a day, so its catalog entry, the CLI Hypergate looks for, the file it connects (`~/.kotrain/settings.json`) and its gateway tool prefix all say Kotrain, at kotrain.com.

### Bug fixes

- **Adding the GitHub server failed.** Remote servers accept a bearer token as well as OAuth now, the manager shows which one a server is really using, and the sign-in escape hatch stays out of your saved configuration.
- **Vercel signed in through the wrong door**, and now uses first-party OAuth like the other providers.
- **The logo on a provider's consent screen was missing.** It pointed at the SVG favicon, and consent screens re-encode whatever logo they are given, so the gate now ships as a raster mark and shows up on the page where you approve access.
- **Update controls stayed readable in a narrow window** instead of collapsing into a wrapped pill halfway through the update flow.
- On the site: the hero's backdrop no longer cuts off square at its corners, the warp ring keeps moving instead of stuttering, and the release notes page has the link-preview metadata it was missing.

### Performance improvements

- **A harness that starts Hypergate itself now shares the servers already running.** Spawning the gateway in stdio mode used to start a private copy of every managed server, so three open editors meant three copies of each server, three database connections and three sets of logs. It looks for the daemon already running on the machine first, and only runs the servers itself when there is none.
