# Find the right tool, and know it's the right one

Everything since v0.20.0, including the v0.21.0 changes that were never released on their own.

### Features

- **Command-line tools can be looked up, not just detected.** Search for any tool and Hypergate answers from its curated set, the npm registry, and Homebrew core, with the install command for the machine you are on.
- **The official Playwright CLI ships in the catalog.** `@playwright/cli` is the token-efficient way to hand an agent a browser, alongside a new entry for the Playwright MCP server.
- **Every search result says whether it is the recommended one.** A line under each MCP server and CLI states what is actually known about its publisher, and names the provider's own route when the result is not it.
- **GitHub sign-in can be set up in the app.** GitHub registers no OAuth app for you, so Hypergate now walks you through creating one once, with the exact callback URL to paste, and keeps the credentials in your OS keychain.
- **A trust chip and its explanation always agree.** Rows are labelled Official, Verified publisher, Community, or Unverified from one verdict.
- **Adding a catalog server offers every way to connect it.** GitHub is one entry with browser sign-in, a personal access token, and running it locally.
- **UI changes now ship with before and after screenshots.** A pull request template and an agent guide make the visual evidence part of the review.

### Bug fixes

- **GitHub browser sign-in always failed.** It reported missing environment variables and rolled the server back; it now offers the one-time setup that makes it work.
- **The Fetch server could never start.** It pointed at an npm package that does not exist and now runs the reference server from PyPI.
- **Running GitHub locally used an unmaintained package.** It now uses GitHub's own container image.
- **A third-party server could be labelled Official.** A verified publisher proves who published something, not that they are the service it connects to, and rows now say which.
- **Every community server was told to use GitHub instead.** Recommendations no longer read a `github.com` homepage as a claim about GitHub.
- **The Postgres server's status is honest.** Its reference package is marked unsupported upstream, and the entry now says so.
- **Installer failures and update retries report the real error.** The updater surfaces what actually went wrong instead of a generic message.

### Performance improvements

- **The release-notes page stops burning CPU.** Its animation and resize handling no longer redraw continuously.
