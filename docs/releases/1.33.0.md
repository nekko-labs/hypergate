# The Midnight gate, from Dock to browser tab

- Hypergate's launcher, browser and MCP connection icons now share a starry Midnight background and a softer violet-to-cyan ring inspired by the app and website. The macOS menu-bar icon stays monochrome so macOS can tint it.

- Upgraded an npm install and still see the old launcher icon? Run `hypergate shortcut install` to refresh it. On Windows, add `--desktop` if you also want to refresh the optional desktop shortcut.
