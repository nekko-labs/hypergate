# Antigravity CLI joins the tool catalog

Install Google's Antigravity CLI from Hypergate, so your Google AI plan can power the apps that drive it.

### Features

- **Antigravity CLI (`agy`) is in the recommended tools.** Google stopped Google-account sign-in for Gemini CLI on June 18, 2026; Antigravity CLI is where a Google AI Pro or Ultra plan runs from a terminal now, and `agy acp` is how apps like Nekko Agent use that plan. Hypergate installs it with Google's own installer script (PowerShell on Windows, the shell script on macOS and Linux), and agents can ask for it with `hypergate__cli_install_request`. Signing in stays in your terminal: run `agy` once, pick a theme, and finish Google sign-in in the browser.
