# A minimized Mac window can come back

One fix, for a trap: on macOS, minimizing the manager window left you with no Dock icon, no app switcher entry, and Open manager doing nothing, so the window was effectively gone until you quit and relaunched. Minimizing is now safe.

### Bug fixes

- **The app is in the Dock while its window is open.** Hypergate used to stay a menu-bar-only accessory even with the manager window on screen, which is why a minimized window had no Dock tile to come back from and the app never appeared in Cmd-Tab. The window now promotes Hypergate to a regular app for as long as it is open: Dock icon, app switcher entry, and a reachable menu bar. Closing to the tray returns it to a quiet menu-bar-only agent, exactly as before.
- **Clicking the Dock icon brings the window back**, including from minimized.
- **Open manager restores a minimized window.** The tray menu's Open manager, double-clicking the tray icon, and launching Hypergate a second time all un-minimize the window first; each of them previously did nothing at all against a minimized window, on every platform.
