# Development runs leave the login item alone

### Bug fixes

- **A development daemon no longer rewrites your login item.** 1.31.0 started repairing a "start at login" entry that no longer worked, and a daemon run from a source checkout (`npm run dev`) or against its own `HYPERGATE_DIR` could take that as its cue and point the entry at the checkout. Only an installed copy repairs the login item now.
