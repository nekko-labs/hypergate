# Installs prefer your system package manager

### Improvements

- **Homebrew, winget and Scoop now come before npm.** Installing a CLI picked whichever route the catalog happened to list first, which meant Claude Code installed through npm on a Mac that had Homebrew sitting right there. Routes are now ranked by what they are and by what this machine can actually run: a system package manager you have, then the vendor's own install script, then npm and friends, with anything whose launcher is missing sorted below all three. A system package manager wins because it is also the thing that will upgrade and remove the tool later.
- **Claude Code gains the routes Anthropic documents.** `brew install --cask claude-code`, `winget install Anthropic.ClaudeCode`, and the native `install.sh`, alongside the npm package it already had. Wrangler, Vercel and the Playwright CLI are unchanged, because their vendors document no system-manager route and Hypergate does not invent one.
- **A Homebrew formula outranks an npm guess in search.** Looking up a tool you do not have yet puts an exact Homebrew match above npm's relevance-ranked results.

### New

- **Vendor install scripts run in-app.** `curl … | bash` and `irm … | iex` routes used to be printed for you to paste into a terminal yourself, which made Hypergate's advice for Bun, Deno, uv, Fly and Claude Code a dead end. They now install with the same live log every other route gets.

  This is the only command Hypergate runs through a shell, so it is gated three ways over: the command has to be byte-identical to one shipped in Hypergate's own catalog, it has to match one of the two documented script forms, and it has to fetch over https from a short allowlist of vendor hosts. Nothing typed into a search box, returned by a registry lookup, or requested by an agent can take this path. Everything else still runs as a plain argument list with no shell involved at all.

### Bug fixes

- **Uninstalling a Homebrew cask names the cask.** `brew install --cask claude-code` derived `brew uninstall claude-code`, which asks Homebrew about a formula of that name rather than the cask that was installed. The flag is carried through to Uninstall and Repair.
- **Bun's Windows install command asked for http.** The curated PowerShell route was copied from Bun's docs as `irm bun.sh/install.ps1`, with no scheme. PowerShell resolves that over http and follows a redirect; it now names `https://` explicitly.
