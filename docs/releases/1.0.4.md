# Intel Mac builds work

A focused patch release for one bug: the Intel Mac download could not start Hypergate.

### Bug fixes

- **The Intel Mac app starts.** The `hypergate-macos-x64.dmg` download — and the older x64 `.pkg` — bundled an arm64 daemon inside an x86_64 shell, so an Intel Mac could not launch the gateway at all. Apple Silicon builds were unaffected. Download this version to replace an older copy; an already-downloaded Intel copy stays broken until it is replaced.
