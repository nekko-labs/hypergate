# The Mac installer opens cleanly

The Mac download now survives the drag to Applications and makes that drag obvious.

### Bug fixes

- **macOS no longer reports Hypergate as damaged.** Every resource is now in place before signing, and release verification checks the app bundle directly before publishing.
- **The DMG is compact and clear.** It opens as a 660×400 installation card with a deep-space background, a hand-drawn cyan arrow, hidden Finder chrome, and no extra files competing with the two install targets.
- **Manual Mac updates explain what is safe to replace.** Hypergate now tells users to quit the app, eject any older Hypergate disk image, and drag the new copy over the old one while servers and settings remain in `~/.hypergate`.
