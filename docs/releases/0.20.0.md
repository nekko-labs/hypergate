# Connect once and stay connected, plus a plugin and a clearer manager

Everything since v0.17.0, including the v0.18.0 and v0.19.0 changes that were never released on their own.

### Features

- **Client connections no longer keep stale tokens.** Clients that can run a command fetch credentials when connecting and retry after a refusal.
- **Claude Code can install Hypergate as a plugin.** The plugin adds the gateway to every project without manual tokens, ports, or JSON.
- **Agents show their own branding.** New Warp and Antigravity entries include their expected configuration and connection snippets.
- **Adding a catalog server is shorter.** The form asks for required credentials first and keeps advanced options one click away.
- **Runtime names are clearer.** The manager uses `cloud`, `local`, and `docker`, with official cloud servers listed first.
- **Analytics is one navigable page.** New tool-ranking and security sections join the existing usage and call views.
- **The gate mark is hollow at every size.** The favicon, manager, tray, and window icons now share the same mark.
- **Theme switching uses one sun-and-moon button.** Switching themes now uses a circular reveal.
- **Dialogs and focus work better with assistive technology.** The manager received a keyboard and screen-reader accessibility pass.
- **Release notes are easier to scan.** Notes use grouped headlines and the release page leads with each release's headline.
- **The site explains the product more directly.** Its title and copy now describe securely connecting agents to external services.
- **Kotrain is named consistently again.** Its catalog entry, CLI, settings path, and gateway prefix all use Kotrain.

### Bug fixes

- **Adding the GitHub server failed.** Remote servers now accept bearer tokens and show the selected authentication method.
- **Vercel used the wrong sign-in flow.** It now uses first-party OAuth.
- **Provider consent screens lacked the logo.** They now receive a raster gate mark that renders reliably.
- **Analytics links could disappear on a fresh install.** Navigation now includes every section in page order, including Security.
- **Update controls wrapped in narrow windows.** Their layout now remains readable throughout the update flow.
- **Several site presentation issues were fixed.** The hero backdrop, warp ring, and release-page metadata now render correctly.

### Performance improvements

- **Harnesses reuse an existing Hypergate daemon.** Stdio mode avoids duplicate servers, database connections, and logs when a daemon is already running.
